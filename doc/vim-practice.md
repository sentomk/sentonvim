# Vim Practice 编辑练习台

在 Neovim 中运行 `:VimPractice`，用 `j` / `k` 选专题，按 Enter 开始。`c` 继续上次专题中尚未完成的题目，`q` 退出专题页。

- 任务、操作提示、目标始终放在独立窗格；宽屏左右排列，窄屏上下排列。
- 在编辑区使用平时的 Vim 按键。目标中的黄色行表示当前仍有差异，绿色行表示匹配。行尾的 `·` 表示空格。
- 内容题检查完整结果，定位题检查高亮处的光标位置。文件题检查真实的临时文件，撤销题分步检查修改、撤销与重做。
- 达到目标并回到普通模式后，约 0.9 秒自动进入下一题。在插入模式、查看任务窗格或离开练习标签页时不会自动切题。
- 每题使用独立缓冲区；重来会重置本题的撤销记录。文件练习只在系统临时目录创建题目文件。
- 完成记录自动保存。跳过不会标为完成。退出时恢复进入练习前的窗口与寄存器。

## 操作

| 按键 / 命令 | 功能 |
| --- | --- |
| F4 / `:VimPracticeMenu` | 返回专题 |
| F5 / `:VimPracticeReset` | 重来本题 |
| F7 / `:VimPracticePrev` | 返回上一题，从初始内容重练 |
| F8 / `:VimPracticeNext` | 跳过 / 下一题 |
| F9 / `:VimPracticeAuto` | 暂停或恢复自动继续 |
| `:VimPracticeCheck` | 显示未完成的位置 |
| `:VimPracticeStop` | 退出并回到原窗口 |
| `:VimPracticeTarget` / `:VimPracticeHint` | 聚焦任务窗格，Tab 返回编辑区 |

`q` 在编辑区保留原本的录制宏功能。HHKB 上不方便按功能键时，可以用对应命令。

## 专题

122 道题，19 个专题：基础移动、插入文本、定位、局部修改、文本对象、可视选择、复制粘贴、跨段跳转、跨行修改、命令行、重复操作、格式整理、文档整理、批量处理、综合任务、撤销重做、代码折叠、文件保存、多窗口工作。

可用 `:VimPractice edit` 直接进入局部修改，或用命令补全选专题。`all` 顺序练习全部题目，`random` 打乱顺序。

内容题按结果验收，允许使用不同的正确编辑方法；提示提供一种可行做法，不评判最少按键。当前练习覆盖 Vim 内置编辑操作，不包含依赖具体项目的 LSP 调试、Git 或第三方插件工作流。

## 本地验证

```sh
nvim --headless -u NONE -i NONE --cmd "set rtp^=$HOME/.config/nvim" \
  -c "luafile $HOME/.config/nvim/tests/vim_practice/catalog.lua" -c 'qa!'
python3 "$HOME/.config/nvim/tests/vim_practice/test_ui.py" "$HOME/.config/nvim"
```

真实按键测试通过 Neovim 自带的 UI/RPC 接口运行，无需安装 Python 依赖。可选的截图输出需要 Pillow。

## 局部修改与文本对象加练

局部修改新增 12 题（共 17 题），练习词中修改、单字符替换、交换字符、逗号边界、整行与行尾修改、计数、点命令和当前行替换。

文本对象新增 16 题（共 21 题），练习 iw/aw、iW、引号、反引号、嵌套圆括号、方括号、花括号、嵌套标签、段落和句子的内部/外围范围。

新题追加在各专题原有 5 题之后，每题都设置了对应的起始光标位置。完成以最终内容为准，提示给出一种练习方式。
